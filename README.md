
# 🌤️ Weather App

A real-time Weather Application built using HTML, CSS, JavaScript, and OpenWeather API.

## 🚀 Features
- Search weather updates for any city worldwide.
- Live temperature display in Celsius.
- Weather details including Humidity and Wind Speed.
- Dynamic weather icons according to the weather conditions.
- Clean and responsive glassmorphism UI.

## 🛠️ Tech Stack
- **HTML5**
- **CSS3** (Flexbox, Grid)
- **JavaScript (ES6+)** (Fetch API, Async/Await)
